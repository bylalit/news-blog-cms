📰 News Blog CMS with Admin Panel

Live project Link: https://news-blog-cms.onrender.com

A full-featured News Blog CMS built using Node.js, Express.js, and MongoDB, designed to manage news articles efficiently with a secure Admin Panel. This project allows admins to create, update, delete, and manage news content while providing users with a clean and responsive news reading experience.

🚀 Features of
🔐 Admin Panel

-> Secure Admin Authentication (Login / Logout)

-> Create, Edit, Delete News Articles

-> Manage Categories

-> Upload & Manage Images

-> Dashboard for content management

🗞️ News Blog

-> Display latest news articles

-> Category-wise news filtering

-> Article preview with short description

-> Responsive UI for all devices

🛠️ Tech Stack Formate

-> Backend: Node.js, Express.js

-> Database: MongoDB

-> Template Engine: EJS

-> Authentication: Session-based Authentication

-> Frontend: HTML, CSS, Bootstrap

-> Other Tools: Mongoose, Multer (for image upload)

📂 Project Highlights Details

-> MVC-based project structure

-> RESTful routing api

-> Clean and scalable code write

-> Admin-controlled content management system

-> SEO-friendly article structure

🎯 Purpose of the Project

This project was created to understand backend development, CRUD operations, authentication, and CMS architecture using the MERN backend stack (Node + MongoDB). It is suitable for real-world news/blog platforms and can be extended with roles, comments, and API support.
